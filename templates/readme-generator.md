# Генератор идеального README.md

**Когда использовать:** Когда создал новый пет-проект, код уже написан, а оформлять репозиторий руками лень.

**Промпт:**
> Ты — опытный Open Source разработчик. Напиши красивый, профессиональный и структурированный README.md для моего проекта.
> 
> Краткое описание проекта: [ОПИСАТЬ СУТЬ, например: телеграм-бот для поиска дешевых билетов].
> Стек технологий: [ЯЗЫК, ФРЕЙМВОРК, БАЗА ДАННЫХ].
> Как запустить: [КРАТКАЯ ИНСТРУКЦИЯ, например: npm install, потом npm start].
> 
> Требования:
> 1. Используй стильные бейджи (shields.io) в самом начале и уместное количество эмодзи.
> 2. Структура документа: О проекте, Стек технологий, Установка, Использование, Контакты.
> 3. Добавь плейсхолдеры в квадратных скобках для скриншотов, чтобы я потом сам их вставил.
> 4. Выведи готовый результат в одном блоке кода Markdown.
