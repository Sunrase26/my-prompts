# 🪄 My Prompt Library: Vibe-Coding Spells

![GitHub last commit](https://img.shields.io/github/last-commit/Sunrase26/my-prompts?style=flat-square&color=8A2BE2)

Личная база знаний и коллекция отборных промптов для ChatGPT, Claude и Copilot. 
Этот репозиторий — мой арсенал для делегирования рутины нейросетям в учебе, разработке и повседневных задачах.

## 🗂 Структура

Репозиторий разбит на категории для быстрого поиска нужного контекста:

* **`/study`** — Выжимки из лекций, конспекты, генерация идей для эссе, подготовка к сессии.
* **`/coding`** — Объяснение багов, написание тестов, рефакторинг, регулярные выражения.
* **`/daily`** — Шаблоны вежливых писем, тайм-менеджмент, бытовые задачи.
* **`/templates`** — Системные промпты и настройки ролей для кастомных GPT.

## 🚀 Как использовать

Каждый файл содержит описание ситуации и сам промпт с `[ПЛЕЙСХОЛДЕРАМИ]`, которые нужно заполнить своими данными перед отправкой ИИ.

**Пример использования:**
> Ты — строгий, но справедливый Senior разработчик. Объясни мне причину возникновения ошибки `[ВСТАВИТЬ ЛОГ]` в коде на `[ЯЗЫК]` и предложи 2 варианта исправления, не давая сразу готовый код.
