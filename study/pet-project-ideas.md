# Генератор идей для учебных пет-проектов

**Когда использовать:** Когда нужен проект для курсовой, диплома или просто для портфолио, но в голову ничего не лезет.

**Промпт:**
> Выступи в роли Senior-ментора. Я студент и базово знаю [ПЕРЕЧИСЛИТЬ ТЕХНОЛОГИИ/ЯЗЫКИ, например: Python, SQL, HTML].
> 
> Придумай 3 нетривиальные идеи для пет-проекта, которые удовлетворяют условиям:
> 1. Решают реальную повседневную проблему (без заезженных "калькуляторов" и "to-do листов").
> 2. Проект реально сделать за 2-3 недели по вечерам.
> 3. Он будет круто смотреться в резюме для джуниора.
> 
> Для каждой идеи кратко распиши базовую архитектуру и какие библиотеки понадобятся.
