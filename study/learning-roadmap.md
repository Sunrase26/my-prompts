# Генератор индивидуального плана обучения (Roadmap)

**Когда использовать:** Когда нужно освоить новую технологию или язык, но нет четкого понимания структуры и последовательности изучения.

**Промпт:**
> Выступи в роли опытного ментора. Составь для меня пошаговый план обучения (Roadmap) по технологии: [ВСТАВИТЬ ТЕХНОЛОГИЮ, например: PostgreSQL / React / Основы Linux].
> 
> Мой текущий уровень: [Новичок / Знаю базовый синтаксис / Уверенный джуниор].
> Моя цель: [Найти стажировку / Написать свой пет-проект / Сдать экзамен].
> 
> Разбей план на 4-5 логических этапов (от простого к сложному). Для каждого этапа:
> 1. Укажи 3 ключевые концепции, которые нужно понять.
> 2. Предложи одну маленькую практическую задачу для закрепления материала.
> 3. Подсвети "красные флаги" — частые ошибки новичков на этом этапе.
