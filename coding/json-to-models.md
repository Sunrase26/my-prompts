# Генератор типизации и моделей данных из JSON

**Когда использовать:** Когда получаешь от сервера большой JSON-ответ и нужно быстро создать под него строгие интерфейсы, классы или дата-классы.

**Промпт:**
> Ты — Senior разработчик. У меня есть следующий JSON-ответ от внешнего API: 
> 
> [ВСТАВИТЬ JSON ИЛИ ЕГО КУСОК]
> 
> Сгенерируй для него строгие типы данных на языке/фреймворке [ВСТАВИТЬ, например: TypeScript / Python Pydantic / Java / Go / C#]. 
> 
> Требования к коду:
> 1. Выведи только готовый код без лишних пояснений.
> 2. Грамотно обработай вложенность объектов (создай для них отдельные интерфейсы/модели).
> 3. Добавь комментарии к неочевидным полям.
> 4. Предположи, что некоторые поля (например, id или description) могут приходить как null, и сделай их опциональными (Optional / Nullable).
