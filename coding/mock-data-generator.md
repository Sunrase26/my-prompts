# Генератор реалистичных тестовых данных (Mock Data)

**Когда использовать:** Когда пишешь код или настраиваешь базу данных, и нужно быстро заполнить систему правдоподобной информацией для проверки.

**Промпт:**
> Сгенерируй тестовые данные для моего проекта. 
> Мне нужно [КОЛИЧЕСТВО, например: 10] записей в формате [JSON / CSV / SQL INSERT].
> 
> Структура данных:
> [ОПИСАТЬ ПОЛЯ, например: id, ФИО, email, номер телефона, дата регистрации, статус заказа].
> 
> Требования:
> 1. Данные должны выглядеть максимально реалистично (настоящие форматы имен, корректные email-адреса и телефоны).
> 2. Сделай данные разнообразными (разные домены почт, даты в случайном порядке в пределах последнего года).
> 3. Выведи только сгенерированный код без лишних текстовых пояснений.
