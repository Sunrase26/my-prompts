# Переводчик кода (Code Translator)

**Когда использовать:** Когда нашел готовое решение на одном языке программирования, а тебе нужно адаптировать его под свой стек.

**Промпт:**
> Ты — Senior разработчик-полиглот. Переведи следующий код с языка [ИСХОДНЫЙ ЯЗЫК] на язык [ЦЕЛЕВОЙ ЯЗЫК].
> 
> Исходный код:
> [ВСТАВИТЬ КОД]
> 
> Требования:
> 1. Сохрани исходную логику работы алгоритма.
> 2. Используй идиоматические конструкции целевого языка (пиши так, как принято в сообществе этого языка, а не делай слепую кальку).
> 3. Если в целевом языке есть встроенные функции, которые делают код короче — используй их.
> 4. Кратко объясни главные отличия в подходах между этими двумя языками для данной задачи.
