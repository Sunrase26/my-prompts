# Конструктор SQL-запросов

**Когда использовать:** Когда нужно составить сложный запрос к БД или оптимизировать существующий.

**Промпт:**
> Напиши SQL-запрос для СУБД [PostgreSQL/MySQL/SQLite] со следующей структурой таблиц:
> [СХЕМА ТАБЛИЦ]
> Задача запроса: [ЧТО НУЖНО ВЫБРАТЬ/ОБНОВИТЬ].
> Добавь комментарии к неочевидным объединениям (JOIN) и агрегациям.
