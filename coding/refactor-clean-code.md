# Рефакторинг и оптимизация читаемости кода

**Когда использовать:** Когда код работает, но выглядит перегруженным, неаккуратным или трудночитаемым.

**Промпт:**
> Ты — эксперт по архитектуре и чистому коду на [ЯЗЫК]. 
> Проведи рефакторинг следующего фрагмента:
> 
> [ВСТАВИТЬ КОД]
> 
> Требования:
> 1. Сделай код чистым, модульным и читаемым по стандартам языка (Clean Code / PEP8 / Style Guide).
> 2. Улучши названия переменных и функций, чтобы они говорили сами за себя.
> 3. Устрани дублирование логики и лишнюю вложенность условий (if/else).
> 4. Не меняй входные и выходные данные программы — логика должна работать идентично.
> 5. Напиши краткий список: что именно было улучшено и почему.
