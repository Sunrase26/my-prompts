# Мастер регулярных выражений (Regex)

**Когда использовать:** Когда нужно вытащить данные из текста (например, все email-ы или номера телефонов), либо когда нашел чужой Regex и пытаешься понять, что он делает.

**Промпт:**
> Ты — эксперт по регулярным выражениям (Regex). 
> 
> [ВЫБЕРИ ОДИН ИЗ ВАРИАНТОВ НИЖЕ И УДАЛИ ЛИШНЕЕ]
> 
> **Вариант А (Написать Regex):**
> Напиши регулярное выражение для языка [Python / JavaScript / Java], которое будет искать в тексте следующее: [ОПИСАТЬ, ЧТО ИЩЕМ, например: номера российских паспортов]. 
> Обязательно объясни, что означает каждый спецсимвол в твоем выражении.
> 
> **Вариант Б (Объяснить Regex):**
> Объясни простым языком, что делает это регулярное выражение: [ВСТАВИТЬ REGEX]. 
> Разбери его по частям и приведи 3 примера текста, которые под него подходят, и 3 примера, которые НЕ подходят.
