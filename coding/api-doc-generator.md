# Генератор API-документации (Swagger/OpenAPI)

**Когда использовать:** Когда написал бэкенд (ручку/эндпоинт) и нужно оформить к нему красивую документацию для фронтендеров или преподавателя.

**Промпт:**
> Я написал эндпоинт для своего API на [ЯЗЫК / ФРЕЙМВОРК].
> 
> Вот код функции/контроллера:
> [ВСТАВИТЬ КОД]
> 
> Сгенерируй для него полную документацию в формате OpenAPI (Swagger) в виде YAML файла.
> 
> Обязательно включи:
> 1. Метод и путь (URL).
> 2. Описание параметров запроса (Query, Path, Body).
> 3. Успешный ответ (200/201) с примером JSON.
> 4. Основные коды ошибок (400, 401, 404, 500) с примерами сообщений.
