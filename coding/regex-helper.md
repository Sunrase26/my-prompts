# Генератор регулярных выражений (RegEx)

**Когда использовать:** Когда нужно составить или расшифровать сложное регулярное выражение.

**Промпт:**
> Напиши регулярное выражение для задачи: [ОПИСАНИЕ ЗАДАЧИ].
> Язык программирования: [ЯЗЫК].
> Предоставь 3 примера строк, которые должны подходить, и 3 примера, которые не должны подходить.
