# ИИ-DevOps: Генератор Dockerfile и Docker Compose

**Когда использовать:** Когда пет-проект готов, и его нужно "завернуть" в контейнеры для удобного запуска, а писать конфиги с нуля нет времени.

**Промпт:**
> Ты — DevOps-инженер. Напиши оптимальный `Dockerfile` и `docker-compose.yml` для моего проекта.
> 
> Стек технологий:
> - Бэкенд/Скрипт: [ВСТАВИТЬ ЯЗЫК И ФРЕЙМВОРК, например: Python/FastAPI]
> - База данных: [ВСТАВИТЬ БД, например: PostgreSQL или SQLite]
> - Зависимости: [КАК УСТАНАВЛИВАЮТСЯ, например: через requirements.txt]
> 
> Требования:
> 1. Используй легковесные базовые образы (например, slim).
> 2. Пропиши правильный порядок запуска (если есть база данных, бэкенд должен ждать её готовности).
> 3. Добавь подробные комментарии к каждой инструкции, чтобы я понимал, как это работает, и мог ответить на вопросы преподавателя.
