# Генератор Docstrings и комментариев

**Когда использовать:** Когда написал сложную функцию или класс, и нужно быстро сгенерировать для нее правильное описание по стандартам языка (например, JSDoc для JavaScript или PEP-257/Sphinx для Python).

**Промпт:**
> Ты — Senior разработчик. Напиши качественную документацию (docstring / JSDoc) для следующего кода.
> 
> Код:
> [ВСТАВИТЬ КОД ФУНКЦИИ ИЛИ КЛАССА]
> 
> Требования:
> 1. Используй общепринятый стандарт документации для этого языка программирования.
> 2. Опиши, что делает функция (кратко, в 1-2 предложениях).
> 3. Опиши все принимаемые аргументы (params/args) и их типы.
> 4. Опиши возвращаемое значение (return) и его тип.
> 5. Укажи, какие исключения (exceptions/errors) может выбросить этот код, если это применимо.
> 6. Выведи только готовый код с добавленными комментариями.
