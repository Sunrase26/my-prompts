# Генератор модульных тестов (Unit Tests)

**Когда использовать:** Когда функция уже написана, но нужно быстро покрыть её тестами и проверить на граничных случаях.

**Промпт:**
> Ты — Senior QA Automation инженер на [ЯЗЫК].
> Напиши модульные тесты для следующего кода с использованием фреймворка [pytest / Jest / JUnit / другое]:
> 
> [ВСТАВИТЬ КОД]
> 
> Требования:
> 1. Покрой позитивные сценарии (happy path).
> 2. Проверь граничные случаи: пустой ввод, null/None, экстремальные значения, некорректные типы данных.
> 3. Добавь краткие комментарии к каждому тесту с пояснением логики проверки.
