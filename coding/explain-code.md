# Пошаговый разбор чужого кода

**Когда использовать:** Когда открываешь чужой проект, решение задачи с лекции или код из интернета и нужно быстро понять, как именно он работает.

**Промпт:**
> Ты — опытный ментор по программированию на [ЯЗЫК]. Разбери следующий фрагмент кода:
> 
> [ВСТАВИТЬ КОД]
> 
> 1. Объясни общую суть: какую задачу решает этот код?
> 2. Разбери логику по шагам: что делает каждая ключевая строчка/блок?
> 3. Если есть неочевидные фишки языка или синтаксический сахар — объясни их отдельно.
> 4. Оцени алгоритмическую сложность (Big O) по времени и памяти.
